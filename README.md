# CarsAnalytics.ExperienceApi

A backend service for the CarsAnalytics platform, responsible for user‑generated content and interaction features, including reviews, ratings, favorites, comparisons, comments, and user experience data.

This service complements **CarsAnalytics.SystemApi**, which manages core catalog data (territories, regions, car models, statistics, users, roles, authentication).

## 🚀 Overview

CarsAnalytics.ExperienceApi is a modular, scalable .NET backend designed to support all interactive and social features of the CarsAnalytics platform, similar to user‑experience sections on sites like *Edmunds.com*.

The API provides:

- Reviews and ratings for car models  
- Favorites (saved cars)  
- Comparisons between multiple models  
- User ownership experience  
- Comments and discussions  
- Pagination, validation, and access control  
- Clean separation of layers  
- Full test coverage (Controllers, Services, Validators)  
- Automated project structure generation  
- Clear documentation and maintainability focus
